# WordLab

**Персональний простір для вивчення англійських слів.**

Я створила WordLab для себе — під свої навчальні потреби, спосіб запам’ятовування та візуальні вподобання. Мені хотілося мати власні колекції слів, кілька способів практики та інтерфейс, до якого приємно повертатися.

Так особиста потреба перетворилася на невеликий вебзастосунок, який я самостійно розробила за допомогою AI-інструментів.

## Чому з’явився цей проєкт

Під час вивчення англійської я працюю зі словами, термінами та довгими поясненнями. Для мене важливо тренувати саме потрібну лексику, повертатися до складних слів і перемикатися між різними вправами.

Я хотіла сама визначати, як організовані мої словники, як поводяться картки та як виглядає мій навчальний простір. Тому WordLab поступово формувався навколо моїх реальних сценаріїв використання: від вставлення списку «слово — переклад» до практики, повторення помилок і збереження прогресу.

## Моя роль та використання AI

Це мій особистий проєкт як розробниці, створений у співпраці з AI.

Я формувала ідею, визначала функціональні вимоги, обирала пріоритети, задавала візуальний напрям і давала зворотний зв’язок після використання. ChatGPT / Codex допомагав генерувати й доопрацьовувати код, реалізовувати взаємодії та перевіряти логіку.

Робота відбувалася ітеративно: я пробувала застосунок на своїх словах, помічала незручності, уточнювала вимоги й покращувала результат разом з AI. Наприклад, так з’явилися перетягування колекцій, гортання карток, режим фокусу та адаптація довгого тексту з обох боків картки.

Для мене WordLab — також практика перетворення власної потреби на продукт: від задуму та вимог до робочого інструмента, яким я можу користуватися щодня.

## Що вміє WordLab

- **Власні колекції:** створення, перейменування, автоматичні назви, видалення з можливістю повернення та зміна порядку перетягуванням.
- **Робота зі словами:** додавання по одному або списком, редагування перекладів, пояснень і речень, пошук англійською та українською.
- **Гнучка практика:** вибір кількох колекцій, кількості слів, напрямку перекладу та фільтра.
- **Повторення:** позначення складних слів зірочкою, раунди помилок і планування наступних повторень.
- **Картки:** 3D-переворот, нахил за курсором, гортання, адаптивний текст і повний перегляд довгих пояснень.
- **Особистий простір:** кольори й іконки колекцій, згортання керування та режим концентрації.
- **Збереження:** продовження тренування з місця зупинки, експорт колекції у TXT та резервна копія всіх даних у JSON.
- **Локальне AI-озвучення:** американський чоловічий голос Onyx у Voicebox / Kokoro 82M, кеш аудіо, повільне відтворення та окремий вибір браузерного голосу.

## Режими практики

| Режим | Що можна робити |
| --- | --- |
| Картки | Пригадувати значення, перевертати картку й оцінювати себе |
| Увесь список | Переглядати слова в обох напрямках, приховувати й відкривати відповіді |
| Знайди пару | Поєднувати слова з їхніми значеннями |
| Обери відповідь | Вибирати правильне значення серед варіантів |
| Напиши відповідь | Вводити переклад або англійське слово |
| Диктант | Слухати слово й записувати його англійською |
| Слово в реченні | Заповнювати пропуск у реченні |
| Склади слово | Збирати англійське слово з літер |
| Повторення | Самостійно оцінювати знання та планувати наступне повторення |

Практика підтримує українські переклади й англійські пояснення. Слова без англійського визначення не потрапляють у вправи, для яких воно потрібне.

## Як додати свій список

Один запис — один рядок. Між англійським словом і перекладом потрібен розділювач із пробілами: ` – `, ` — ` або ` - `.

```text
backbone – хребет, основа, база, фундамент
evolve – розвиватися, еволюціонувати
connectivity - зв'язок
```

Англійське пояснення й речення можна додати через `|`:

```text
volatile – енергозалежний | requiring power to retain data | RAM is volatile, so its data disappears when the power is off.
```

Якщо пояснення не потрібне, але є речення:

```text
chorus – приспів | | We sing the chorus together.
```

Речення має містити відповідне англійське слово або позначку `{{word}}`. Коми в перекладі залишаються частиною одного запису. В одній колекції може бути до 1000 слів.

## Запуск

Застосунок міститься в одному файлі — [index.html](index.html). Його можна завантажити й відкрити в браузері без встановлення залежностей або збирання проєкту.

Для роботи зі сталою локальною адресою можна запустити простий сервер із папки проєкту, якщо встановлено Python:

```bash
python3 -m http.server 8000
```

Після цього відкрити <http://localhost:8000>.

## Озвучення Onyx через Voicebox

### Перший запуск на Mac

1. Встановити [Voicebox](https://voicebox.sh/) і створити голос: **Built-in voice → Kokoro 82M → Onyx → English**. Один раз перевірити генерацію у самій програмі й дочекатися завантаження моделі.
2. Завантажити репозиторій (**Code → Download ZIP**) і розпакувати. `index.html`, `voicebox_bridge.py` та `Start-WordLab.command` мають лежати поруч.
3. У Terminal перейти до розпакованої папки та виконати:

   ```bash
   python3 voicebox_bridge.py
   ```

   Потрібен Python **3.9+**; додаткові бібліотеки й ключ API не потрібні. Перевірка версії: `python3 --version`. За потреби встановити Python з [python.org](https://www.python.org/downloads/macos/).

4. Запускник відкриє <http://127.0.0.1:17494>. У WordLab відкрити **Налаштувати озвучення → Перевірити підключення → Проба голосу**.
5. Якщо профіль створено заново, перевірка знайде єдиний доступний профіль Onyx і підставить його ID. Натиснути **Зберегти налаштування**. Якщо таких профілів кілька, скопіювати ID потрібного з <http://127.0.0.1:17493/profiles> вручну.

Для наступних запусків можна один раз виконати `chmod +x Start-WordLab.command`, потім відкривати цей файл подвійним кліком. Альтернатива — завжди запускати командою Python вище. Якщо macOS обмежує відкриття завантаженого `.command`, використовувати Terminal; вимикати захист системи не потрібно.

Залишати **Voicebox і вікно запускника** відкритими для генерації нових слів. Зупинка запускника — **Ctrl+C**. Кнопка «Зупинити» у WordLab зупиняє очікування/відтворення в браузері; уже розпочата генерація може завершитися в історії Voicebox.

### Локальний файл і GitHub Pages

Після запуску `voicebox_bridge.py` можна також відкрити `index.html` подвійним кліком або [GitHub Pages](https://bulka0801.github.io/WordLab/). Стандартна адреса в налаштуваннях WordLab — `http://127.0.0.1:17494/voicebox`.

Запускник потрібен через CORS: поточний Voicebox за замовчуванням дозволяє лише кілька локальних адрес, до яких не входять `file://` і GitHub Pages. Адаптер працює лише на `127.0.0.1`, передає обмежені запити до Voicebox на порту `17493` та дозволяє сторінку цього проєкту (`https://bulka0801.github.io`), локальну сторінку запускника й локальний HTML-файл. Профілі не редагуються; генерація обмежена англійським Kokoro Onyx і текстом до 200 символів. Інші сайти й довільні проксі-запити не підтримуються.

Браузер може попросити дозвіл на локальне підключення. Якщо браузер або налаштування системи блокують його, користуватися локальною сторінкою запускника. Не потрібні публічний тунель, відкриття порту в роутері або вимкнення захисту браузера. `127.0.0.1` на телефоні означає сам телефон; він не підключиться до Voicebox на Mac.

**Перед переходом із `file://` на localhost зберегти JSON-копію колекцій** і відновити її на новій адресі: ці сторінки мають окремі сховища браузера. Автоматичної синхронізації між локальним файлом, localhost та GitHub Pages немає.

### Кеш і помилки

- Аудіо кешується в IndexedDB: до 128 записів / 32 MiB, старі записи видаляються першими. Ключ містить адресу сервера, ID профілю й точний текст. Повільний режим відтворює той самий запис зі збереженням висоти голосу.
- За недоступності IndexedDB використовується обмежений кеш у пам’яті поточної вкладки. У браузері можуть діяти власні обмеження зберігання; нові й видалені з кешу слова потребують Voicebox.
- Кеш не входить у JSON-копію. **Очистити кеш аудіо** не видаляє колекції чи прогрес.
- Запити виконуються лише після натискання кнопки. Якщо Voicebox не запущений або профіль відсутній, WordLab показує повідомлення. Голос не змінюється автоматично: для альтернативи є **Обрати голос браузера**.
- Після переходу на іншу картку пізня відповідь API не запускає старе слово. Сучасний API з чергою (`generating → completed`) і відповідь із готовою генерацією обробляються окремо.

API перевірено за [кодом Voicebox](https://github.com/jamiepine/voicebox/tree/main/backend/routes): `POST /generate`, `GET /history/{id}`, `GET /audio/{id}`. Перевірка логіки використовує локальний тестовий сервер; справжню вимову та дозволи браузера потрібно перевірити на комп’ютері з Voicebox.

## Технології та дані

- HTML, CSS та JavaScript без фреймворків.
- CSS 3D transforms для карток.
- `localStorage` для колекцій, налаштувань, прогресу й поточного тренування.
- Voicebox REST API / Kokoro Onyx для локального AI-озвучення, Web Speech API як окремий варіант.
- IndexedDB для кешу аудіо; Python stdlib для локального запускника.
- `ResizeObserver` для адаптації тексту до розміру картки.

Дані зберігаються в поточному браузері. Для перенесення на інший пристрій або збереження всіх колекцій і прогресу є експорт та відновлення JSON-копії.

Основні вправи працюють локально. Нове AI-озвучення потребує запущеного Voicebox і адаптера; браузерний голос залежить від голосів пристрою. Моделі Voicebox завантажуються окремо й не входять до цього репозиторію.
